All data is hand-entered JSON in the data/ folder of the site's repository. A checker runs with the tests (npm test) and the build stops on any error.

Polyomino entries

One file per polyomino at data/polyominoes/<cells>/<id>.json, where the ID is canonical (see Notation): 

{
  "id": "fe70",
  "names": ["fe70", "gun B(1.2^3.1^3)"],
  "note": "Optional free text.",
  "seeAlso": ["tulleken-2019", "fe70-org"],
  "properties": {
    "rectifiable": { "status": "open", "ref": "dahlke-gun", "refDetail": "section 26" },
    "order": { "status": "open", "lower": 100 }
  }
}

seeAlso lists reference keys for sources that discuss the piece without being the first publication of one of its results.

Every property record has:

  • status: proven (published proof), computed (computer search), or open.
  • value: required unless open, forbidden when open.
  • lower, upper: optional bounds.
  • ref: a key in data/references.json, the first publication of the result. Required unless open.
  • refDetail, reason, note: optional text.

Property keys and value types:

  • rectifiable, tilesPlane: true or false.
  • order: a positive integer. oddOrder: an odd integer or "none".
  • smallestRectangles: a list of [width, height].
  • smallestSquare: a side length or "none".
  • primeRectangles: { "rectangles": [[w, h], ...], "complete": true }.
  • minColors: 1 to 4.

Tilings

One file per tiling at data/tilings/<id>/<width>x<height>.json. Add a suffix such as -2 or -odd to store several tilings of the same size. Each placement is an orientation and the top-left corner of that orientation's bounding box: 

{
  "width": 4,
  "height": 2,
  "ref": "some-paper",
  "placements": [
    { "o": 0, "x": 0, "y": 0 },
    { "o": 2, "x": 1, "y": 0 }
  ]
}

The checker places every copy and rejects overlaps, gaps and copies sticking out. It also cross-checks the tiling against the entry: no fewer copies than the order, no odd count below the odd order, and no tiling that uses fewer colors than the recorded fewest colors.

References

data/references.json maps keys to kind (publication or website), authors, title, and optionally year, venue, volume, pages, plus a doi or url. Set checked to true once the details are verified against the source.
