Results with status computed and the source "this catalogue's solver" come from exhaustive searches run by tools/solve.ts in the site's repository. A search that runs out of its step budget proves nothing and is not recorded. Every search is exhaustive in the sense stated below, so the results are proofs by computer, as reliable as the code.

Order and smallest rectangles

For k = 2, 3, ... copies, every rectangle of area k times the piece size is searched for a tiling, filling the first empty cell in reading order. The first k for which some rectangle can be tiled is the order, because every rectangle holding fewer copies was ruled out. All rectangles of that area are searched, so the recorded smallest rectangles are complete, and a tiling of each is stored.

Corner test

The corner of any rectangle must be covered. For a depth d, the test tries to cover every cell within d rows and columns of a corner with copies that stay inside the rectangle. It does this for every possible rectangle size near the corner: each side either shorter than d (so the far wall is within reach) or at least d (then the wall is ignored, which only allows more arrangements). If no arrangement exists for any size, the piece tiles no rectangle.

The test is sound but not complete. Pieces such as the S tetromino force a staircase that leaves any finite corner region, so the test cannot rule them out; such pieces are listed as undecided until a stronger argument is entered.

Strip sweep

Pieces that escape the corner test are swept column by column along one wall of the rectangle, starting at its left wall. The state is which cells of the first h rows (the band) are already covered in the next few columns.

  • With a hard wall at row h, the sweep is exact: returning to an empty state after W columns is a tiling of an h × W rectangle, and never returning proves that no rectangle of height h exists, whatever its width.
  • Without that wall, cells above the band are ignored, which only allows more. If the empty state is still unreachable, no rectangle of height h or more exists, whatever its width.

Excluding every height below h exactly and then all larger heights with the band proves that the piece tiles no rectangle. This settles pieces whose corner forces a pattern that runs along the wall, such as the S tetromino, and it was run with bands of up to 14 rows.

Half-strips

A half-strip is the region between two parallel walls, closed by a third wall at one end. The strict sweep with walls on both long sides decides a half-strip of one width exactly: it tiles if and only if the sweep can go on forever, that is, if its state graph has a cycle reachable from the start. For all widths at once, the band sweep is run along the closed end: it needs a wall with perpendicular walls at both ends and enough depth, which every half-strip provides. If the band sweep can never finish flat, no half-strip of any width can be tiled. A blocked corner test rules out half-strips in the same way.

Plane tilings

A tiling of a torus (the plane modulo a lattice) repeats into a periodic tiling of the plane. The search tries every lattice whose fundamental domain holds up to a few copies. For the other direction, if no arrangement of copies covers a square, even with copies sticking out on every side, the piece does not tile the plane, since every plane tiling covers every square. On heptominoes and octominoes these two tests agree with the known numbers of pieces that tile the plane.

Width-2 pieces

The pieces of width 2 that remained undecided were settled with Dahlke's Gun Theorem (), which classifies all polyominoes of width 2. Their entries cite the theorem rather than a computation.

Checks

The solver was verified against Dahlke's complete list of orders through hexominoes and against Reid's data for heptominoes and octominoes: every order it can reach agrees, and neither the corner test nor the strip sweep rejects a piece known to tile a rectangle.
